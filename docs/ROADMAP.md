# 今後の取り組み予定

2026-11-03 に外部レビュー（v0.81.0 時点）を受けて整理した改善予定。
「間違ったつながりを教えない」「追加した語を迷わず学べる」「学習記録とバックアップを信頼できる」を、
機能追加や語数増加より優先する。

- 状態: ✅ 対応済み / 🔍 現行コードで確認済み（未対応） / 📝 未確認（着手時に再現から）
- 優先度: P1 = データの信頼性・誤学習・主要導線 / P2 = 日常利用での混乱・復帰・アクセシビリティ / P3 = 拡充・長期設計

## 対応済み

| ID | 内容 |
|---|---|
| C01 | number（numb＋er → numer「数」）、remember（member → memor「覚えている」）、former（form＋-er の分解を外す）、religion（解説の lig「結ぶ」に合わせる）の語源分解を修正。remember の解説も修正 |
| C02 | inflation の in- を「否定」から「中へ」に修正 |
| — | track の誤った語源分解（tract「引く」）を外す（07 のレポートから追加した分の見直し） |
| B01 | バックアップから API キーの保管庫（secrets・kv）を除外し、復元時も受け付けない |
| B02 | 回答の連打対策: 画面側は次のカードに移るまでロック、DB 側はカードの読み込みから書き込みまでを 1 トランザクションに |
| B03 | 学習画面の「今日の学習」で、復習の時期が来たカードに加えて、辞書から追加した未学習のカードも始められるように。ホームの件数も同じ数え方に |
| B08 | 画面を開いたままでも、1 分ごと・タブに戻ったときに件数を数え直す |
| B09 | 「すべて消去」で、アプリのキー（nev-）だけを localStorage / sessionStorage から消す（同じドメインの他のアプリには触れない） |
| B10 | バックアップに app・schemaVersion を持たせ、表の許可リスト・行ごとの型と値域・設定の値域を検証。復元は「今のデータに追加」「置き換え」を選べ、取り込む件数を先に表示 |
| B13 | 日→英・穴埋め・ミックスでは、自動読み上げを答えを見たときに行う |
| B16 | 学習の開始に失敗してもボタンが押せないままにならないように |
| B04 | 例文のリンク: 不規則形・代名詞の対応表（is → be、his → he など）を先に引き、語尾を外した語幹が 3 文字未満なら採用しない。-ed は e を残す候補を先に（used → use、united → unite） |
| B06 | 4択: 正解と同じ訳を 1 つでも含む語・類義語・反義語・派生語・同じ表示を誤答から除外。正解も誤答と同じ形式で表示し、候補が足りなくても止まらない |
| B07 | 設定に「AI に送る情報」を追加し、送信内容を明示。学習状況の共有をオフにできる（オフのときは状況を送らず、取得ツールも断る）。ヘルプのプライバシー説明も実態に合わせた |
| B05 | 外部 AI・アプリ内 AI の追加解説を、保存前に型・長さで検証（`sanitizeExtra`）。表示側も文字列以外は描画しない |
| — | ChatGPT / Gemini による語源監査（PR #85）のうち、元データからのフルビルドで確認できた修正を取り込み |
