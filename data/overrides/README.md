# 手動での修正（data/overrides/*.tsv）

自動抽出の誤りや不自然な訳を、頻出語から順に直していくためのファイル（このリポジトリのオリジナルデータ / CC BY-SA 4.0）。
ファイル名の順に読み込み、同じ見出し語に対する指示は後のファイルが優先されます。コンテンツ拡充の各弾ごとに新しいファイルを追加します。

| 指示 | 書式 | 内容 |
|---|---|---|
| `gloss` | `gloss	見出し語	品詞:訳、訳\|品詞:訳` | 訳語を置き換える（品詞: noun verb adj adv prep conj pron det intj num phrase）。書いた順に表示される |
| `drop` | `drop	見出し語` | 見出し語から外す |
| `exclude` | `exclude	形態素ID	見出し語,見出し語` | 語源分解の誤判定を取り除く |
| `noparts` | `noparts	見出し語,見出し語` | 語源分解をまとめて取り除く |
| `parts` | `parts	見出し語	綴り=形態素ID 綴り …` | 語源分解を手で登録する（IDなしの綴りはつなぎ、`w:語` は英語の語基）。自動判定より優先 |

`python3 scripts/data/06_lint.py` で書式・形態素IDの誤りを確認できます（CI でも実行）。
