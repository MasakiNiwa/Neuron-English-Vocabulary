# 韓国語・中国語の訳（外部翻訳の取り込み口）

ここに置いた訳は、`scripts/data/04_build.py` が Wiktionary から自動で集めた訳より優先して使います。
訳がない語・品詞は、これまでどおり Wiktionary の訳（それもなければ日本語）を表示します。

## 置き方

言語ごとのディレクトリ（`ko`・`zh-Hans`・`zh-Hant`）に、タブ区切りの UTF-8 テキストを置きます。
`#` で始まる行と空行は読み飛ばします。

| ファイル | 列 | 例 |
|---|---|---|
| `gloss*.tsv` | key ⇥ 品詞 ⇥ src ⇥ 訳（` \| ` 区切り、最大 4 つ） | `run⇥verb⇥1a2b3c4d⇥달리다 \| 운영하다 \| 작동하다` |
| `morphemes*.tsv` | 形態素の id ⇥ src ⇥ 意味（` \| ` 区切り） | `r:act⇥5e6f7a8b⇥행하다 \| 움직이다` |

- key・品詞・id・src は `08_translation_export.py` の出力（`key`・`pos`・`id`・`src`）をそのまま書き戻します
- ファイルは名前順に読み、同じ語が複数あれば**後のものを使います**。差分は `gloss-2026-12.tsv` のように別ファイルで足せます
- 中国語は簡体字（`zh-Hans`）と繁体字（`zh-Hant`）を別々に置きます。単語の訳は同じ順で並べると、
  ビルドで「繁体 /简体」の組にまとめます（片方だけでも構いません。その場合は両方の字形でその訳を表示します）

## 日本語の見直しと訳を一致させる仕組み（src）

`src` は、訳したときの日本語（品詞＋日本語の訳、語根なら日本語の意味）の指紋（ハッシュ 8 桁）です。
あとで日本語の訳や語根の意味を直すと指紋が変わるので、どの訳が古くなったかが機械的に分かります。

- 古くなった訳もそのまま表示に使います（訳し直すまでのつなぎ）
- `06_lint.py`（CI でも実行）と `04_build.py` が「訳したあとに日本語が変わった訳」の件数と語を警告します
- 見出し語から消えた語の訳も `06_lint.py` が警告します

## 手順

```sh
# 1. 最初の全訳: 訳すもとを 200 件ずつの JSON Lines に書き出す
python3 -I scripts/data/08_translation_export.py /tmp/tr

# 2. 日本語の見直しのあと: まだ訳がない行と、日本語が変わった行だけを書き出す
python3 -I scripts/data/08_translation_export.py /tmp/tr --needed ko,zh-Hans,zh-Hant

# 3. 訳して上の形式の TSV にし、data/translations/<言語>/ に置いてビルド・検査
python3 scripts/data/04_build.py --work … --raw … --repo .
python3 scripts/data/06_lint.py
```

AI で訳すときは、日本語の訳（`ja`）を訳すもとにし、`head`（英単語）・`pos`（品詞）・`en`（英語の定義）を
意味を取り違えないための文脈として渡すと、同じ綴りで意味の違う語（bank の「銀行」と「土手」など）を正しく訳しやすくなります。
`src` は訳さずにそのまま書き戻すよう指示してください。API キーはリポジトリに入れないでください。
