# 韓国語・中国語の訳（外部翻訳の取り込み口）

ここに置いた訳は、`scripts/data/04_build.py` が Wiktionary から自動で集めた訳より優先して使います。
訳がない語・品詞は、これまでどおり Wiktionary の訳（それもなければ日本語）を表示します。

## 置き方

言語ごとのディレクトリ（`ko`・`zh-Hans`・`zh-Hant`）に、タブ区切りの UTF-8 テキストを置きます。
`#` で始まる行と空行は読み飛ばします。ファイルを分けたいときは同じ名前に追記してください。

| ファイル | 列 | 例 |
|---|---|---|
| `gloss.tsv` | key ⇥ 品詞 ⇥ 訳（` \| ` 区切り、最大 4 つ） | `run⇥verb⇥달리다 \| 운영하다 \| 작동하다` |
| `morphemes.tsv` | 形態素の id ⇥ 意味（` \| ` 区切り） | `r:act⇥행하다 \| 움직이다` |

- key・品詞・id は `08_translation_export.py` の出力（`key`・`pos`・`id`）をそのまま使います。
  語・品詞が見つからない行はビルド時に警告します
- 中国語は簡体字（`zh-Hans`）と繁体字（`zh-Hant`）を別々に置きます。単語の訳は同じ順で並べると、
  ビルドで「繁体 /简体」の組にまとめます（片方だけでも構いません。その場合は両方の字形でその訳を表示します）

## 作り方の例

```sh
python3 -I scripts/data/08_translation_export.py /tmp/tr          # 訳すもとを 200 件ずつの JSON Lines に書き出す
# gloss-001.jsonl … を翻訳サービスで訳し、上の形式の TSV にする
python3 scripts/data/04_build.py --work … --raw … --repo .         # 取り込んでビルド
python3 scripts/data/06_lint.py
```

AI で訳すときは、日本語の訳（`ja`）を訳すもとにし、`head`（英単語）・`pos`（品詞）・`en`（英語の定義）を
意味を取り違えないための文脈として渡すと、同じ綴りで意味の違う語（bank の「銀行」と「土手」など）を正しく訳しやすくなります。
API キーはリポジトリに入れないでください。
